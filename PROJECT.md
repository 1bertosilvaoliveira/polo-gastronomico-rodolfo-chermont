# Polo Gastronômico Rodolfo Chermont — O Corredor Criativo da Gastronomia

Repositório oficial do dashboard executivo do projeto do Polo Gastronômico Rodolfo Chermont, na Marambaia, Belém/PA.

## Objetivo
Organizar e apresentar, de forma pública e versionada, dados territoriais, indicadores, estabelecimentos confirmados, evidências e evolução do projeto.

## Estrutura
- `index.html`: dashboard público.
- `README.md`: documentação do projeto.

## Base atual
- 39 estabelecimentos confirmados.
- Trecho 1: 32 estabelecimentos.
- Trecho 2: 7 estabelecimentos.
- 8 trailers.
- Eixo total: aproximadamente 1,60–1,65 km, ainda sujeito à consolidação cartográfica final.

## Governança de dados
Os números devem ser classificados como fato comprovado, dado primário, estimativa, percepção/hipótese ou proposta. O dashboard não deve converter estimativas ou percepções em fatos.

## Atualização
Este repositório será conectado ao Vercel. Alterações na branch `main` deverão gerar nova publicação automaticamente.
